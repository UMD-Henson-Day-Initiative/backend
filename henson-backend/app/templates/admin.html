  3. 3Use Search address to jump the map to a location, then click on the map to drop the pin exactly where the event happens.
  4. 4Set the start/end time and points, and optionally add a link (a website, form, or registration page) — it'll show as a tappable link in the app.
  5. 5Click Save. Changes appear in the app right away — no restart needed.
